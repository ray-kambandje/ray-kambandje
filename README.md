## 🚀 Ce que je construis

| Projet | Description | Stack |
|---|---|---|
| 🚕 **MADEBOCAR** | Plateforme VTC à Kolwezi (RDC) : app mobile client/chauffeur, site web, back-office d'administration et API. | Expo · React · Express · PostgreSQL |
| 🏞️ **Cap Lualaba** | Plateforme de découverte touristique de la province du Lualaba, en partenariat avec le Ministère provincial du Tourisme. Optimisée pour mobile et réseaux lents. | React 19 · Vite · Express 5 · PostGIS |
| 🛒 **BisoMarket** | SaaS multi-tenant de gestion commerciale et de point de vente pour les petits commerces. | React · Express 5 · Drizzle · PostgreSQL |

> Les dépôts de ces projets sont privés (organisation JOSAR Technology).
